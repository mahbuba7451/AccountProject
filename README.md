# Account Project

A simple Java project demonstrating Object-Oriented Programming concepts.

## Features
- Account class
- Account Number, Account Holder Name and Balance attributes
- Default Constructor
- Parameterized Constructor
- Setter Methods
- Getter Methods
- User input using Scanner
- Values are set using Setter Methods
- Information is displayed using Getter Methods

## Files
- Account.java
- AccountApp.java

## Language
Java
