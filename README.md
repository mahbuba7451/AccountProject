# Account Project

A simple Java project demonstrating basic Object-Oriented Programming (OOP) concepts and simple bank account operations.

## Features

- Account Class
- Account Number, Account Holder Name, and Balance attributes
- Default Constructor
- Parameterized Constructor
- Setter Methods
- Getter Methods
- User Input using Scanner
- Deposit Money
- Withdraw Money
- Balance Validation
- Transaction Choice Menu

## Transaction Options

The user can select an operation:

- Press 1 for Withdraw
- Press 2 for Deposit

## Files

### Account.java

Contains:
- Account attributes
- Default Constructor
- Parameterized Constructor
- Setter Methods
- Getter Methods
- `deposit()` Method
- `withdraw()` Method

### AccountApp.java

Contains the `main()` method.

It:
- Takes account information from the user
- Sets values using Setter Methods
- Allows the user to choose Withdraw or Deposit
- Performs the selected transaction
- Displays account information using Getter Methods
- Displays the updated account balance
